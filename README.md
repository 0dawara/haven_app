# Haven App

A modern wallpaper application using the [Wallhaven API](https://wallhaven.cc/), built with Flutter.

## Features ✨

- 🔍 **Search & Filter:** Find wallpapers by tags, categories, resolution, and more.
- 💾 **Save Wallpapers:** Download your favorite wallpapers directly to your device.
- 📤 **Share:** Easily share wallpaper links with your friends.
- 📱 **Multi-platform:** Works seamlessly on Android, iOS, macOS, Linux, and Windows.
- 📦 **Offline Support:** Persists user settings and preferences using Hydrated Bloc.

## Built With 🛠️

- [Flutter](https://flutter.dev) - UI Framework
- [Bloc & Hydrated Bloc](https://pub.dev/packages/flutter_bloc) - State Management & Persistence
- [Wallhaven API](https://wallhaven.cc/help/api) - Data Source
- [Cached Network Image](https://pub.dev/packages/cached_network_image) - Image Caching
- [Share Plus](https://pub.dev/packages/share_plus) - Sharing functionality
- [Device Info Plus](https://pub.dev/packages/device_info_plus) - Device information
